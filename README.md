# LibraryManagementSystem

A library management system built with C#, Entity Framework Core, and SQL Server.
Manages books, authors, publishers, members, and borrowing operations.

> 🚧 **Status:** In active development. Code and full documentation coming soon.

## Tech Stack
- C# / .NET 9
- Entity Framework Core
- SQL Server

## Planned Features
- Relational database design (books, authors, publishers, members, loans)
- Code-First migrations and Fluent API configurations
- Borrowing and returning logic with due dates
- Search and filtering with LINQ
- Unit tests with xUnit
